# 사이 (프로토타입)

두 사람 사이에 직접 들어가 갈등을 푸는 AI 커플 상담사.
상담소에 가려는 커플이 대상이다. 상담사가 먼저 묻고, 단계를 스스로 판단하고, 셋이 함께하는 자리에서는 발언 순서까지 쥐고 진행한다.

> 노방장과는 별개의 실험이다. 이 폴더는 노방장 빌드·배포에 포함되지 않는다(`tsconfig.json`, `.dockerignore`에서 제외).

## 흐름

1. **나 + 상담사 (1:1 비공개)**: 들어오면 상담사가 먼저 말을 건다. 사건 → 감정 → 욕구 → 패턴 → 관계 의지까지 파고든다.
2. **초대**: 충분히 파악되면 상담사가 먼저 "상대도 불러볼까요?"라고 제안하고 초대 링크 카드가 뜬다.
3. **상대 + 상담사 (1:1 비공개)**: 상대도 먼저 1:1로 이야기한다. 먼저 온 사람이 한 말은 전하지 않는다.
4. **👥 함께 상담**: 두 사람 모두 버튼을 누르면 공동방이 열린다. 상담사가 다음에 말할 사람을 지정하고, 차례가 아닌 사람은 입력이 막힌다.
5. **고리 이름 붙이기 → 짧은 설명 → 서로 듣기 → 약속 → 역할극 훈련 → 사이 리포트**
6. 공동 상담 중에도 🔒 버튼으로 언제든 상담사와 1:1로 잠깐 빠질 수 있다.

## 상담 품질을 만드는 장치

| 장치 | 파일 |
|---|---|
| 상담 프로토콜 = 시스템 프롬프트. 상담 전문가가 이 파일만 고치면 상담사가 바뀐다 (Gottman, EFT, IBCT, NVC, CBT, 이마고, 동기강화, 해결중심, 이야기치료) | `protocol/counselor.md` |
| 매 턴 상담사가 먼저 판단(단계, 목표, 기법, 다음 화자, 안전, 초대, 공동 준비)하고 한 마디만 말하는 구조화 출력 | `src/types.ts`, `src/claude.ts` |
| 비공개 분리: 비공개방 상담사는 상대의 비공개 대화를 아예 받지 않는다. 상대가 공유를 허락한 항목만 받는다 | `src/context.ts` |
| 공동방 누설 검사: 공동방에 나가는 모든 상담사 발화를 비공개 자료와 대조해 한 번 더 검사하고, 누설이면 고친 문장을 내보낸다 | `src/claude.ts` `leakCheck` |
| 안전: 폭력·강압통제·자해 신호가 나오면 초대와 공동 상담을 막고, 진행 중이면 공동방을 닫는다 | `src/engine.ts` |
| 가상 커플 자동 상담 + 수퍼바이저 채점(8개 항목, 40점) | `scripts/simulate.ts`, `scripts/scenarios.ts` |

## 실행

```bash
cd sai
npm install

# 실제 상담 (Claude API 키 필요)
ANTHROPIC_API_KEY=sk-ant-... npm start
# → http://localhost:3300

# 키 없이 화면과 흐름만 보기 (상담사가 정해진 말만 함)
SAI_DEMO=1 npm start
```

두 사람을 시험하려면 한 브라우저는 일반 창, 다른 하나는 시크릿 창에서 초대 링크를 연다.

환경변수: `SAI_MODEL`(기본 `claude-opus-5-5`), `SAI_EFFORT`(기본 `medium`, 깊게 하려면 `high`), `PORT`(기본 3300).

## 품질 검증

```bash
npm test                                      # 흐름·비공개·턴 통제·안전 단위 테스트 (API 키 불필요)
ANTHROPIC_API_KEY=... npm run simulate         # 4개 시나리오 자동 상담 + 채점
ANTHROPIC_API_KEY=... npm run simulate -- startup
```

결과는 `data/sim/`에 대화 전문과 채점표(누설 의심 문장, 좋았던 순간, 고칠 점, 프로토콜 수정 제안)로 남는다.
프로토콜을 고치고 → 시뮬레이션 → 점수 비교를 반복하는 것이 "최고의 상담사"를 만드는 루프다. 실제 커플 상담 전문가 한 명이 채점 결과를 검수하면 가장 빠르게 좋아진다.
