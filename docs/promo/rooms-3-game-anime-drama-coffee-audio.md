- **검색어 목록**: 실제 커뮤니티 글 제목과 기사에서 쓰는 표현을 바탕으로 골랐다. 네이버 검색량 수치는 확인하지 않았다(미확인). 네이버 데이터랩이나 키워드 도구로 확인 후 상위 5개만 제목에 쓴다.
- **운영자 공개 문구(모든 외부 글 공통)**: 글 맨 끝에 한 줄 `노방장 만든 사람이라 링크 남깁니다. 광고비 받은 글 아닙니다.` 제휴·광고가 있는 글은 제목 앞에 `[광고]` 또는 `[제휴]`를 붙인다.
- **하지 않는 것**: 다른 사람인 척하는 계정, 지인 동원 추천·댓글, 같은 글 여러 갤러리 복붙, 홍보 금지 게시판에 링크, 질문에 링크만 다는 답. 외부 링크 답변은 하루 1회까지.
- **행동 유도 문장 비율**: 노방장 안 운영 글 5개 중 질문·"댓글 남겨 주세요"로 끝나는 글은 1개 이하. 나머지는 정보로 끝낸다(예: "다음 업데이트는 금요일 오전").
- **지표 공통**: 유입은 `?from=` 값으로 나눈다. 권장 값: `dc`, `naver`, `theqoo`, `arca`, `inven`, `ruli`, `clien`, `quasar`, `ig`, `th`, `yt`, `kakao`. 매일 같은 시간(밤 11시)에 방 유입, 재방문, 채팅 글 수 3개만 기록한다.
- **스포일러 원칙(드라마·애니)**: 줄거리, 회차 전개, 결말, 반전, 등장인물 생사는 쓰지 않는다. 편성일, 플랫폼, 장르, 출연진, 원작 유무 같은 공개 정보만 쓴다. 노방장 채팅 탭에 "스포 있는 글은 제목에 [스포] + 회차 표기" 규칙을 고정한다.

### 8) 입소문 설계 (STEPPS)
- **Social currency**: `/game-test` 결과를 "티어 카드"처럼 디자인(예: "새벽 4시형 응원러"). 결과 카드에 방 이름과 순위 표시. 테스트 상위 % 표시는 실제 참여 데이터로만.
- **Triggers**: "새벽 4시", "11/19" 같은 숫자를 반복 사용. 경기 시작 30분 전 노방장 채팅 탭 고정 글이 매번 같은 형식으로 뜨게 한다.
- **Emotion**: 승패 직후 흥분. 경기 후 채팅 글은 결과 요약 없이 "한 줄 평" 자리만 연다(감정 배출구).
- **Public**: 혜택 이미지에 하단 워터마크 `nobangjang.com 게임 덕후방`. 퍼가도 출처가 남는다.
- **Practical value**: `[혜택]` 한 장, 한국 시간 일정표, 지스타 체크리스트. 저장할 이유가 있는 것만.
- **Stories**: 대표님 1인칭 짧은 글 "단톡방에서 쿠폰 코드가 매번 묻혀서 한 장으로 모으기 시작했다". 운영자임을 밝힌 이야기 자체가 소재.
