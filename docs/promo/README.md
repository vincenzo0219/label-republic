## 2. 공통 원칙
1. **정체를 밝힌다.** 외부 커뮤니티에는 "노방장 만든 사람입니다"를 밝히고 쓴다.
   - 가짜 계정 칭찬, 가짜 후기, 도배, 규칙 우회는 하지 않는다. 강퇴·차단·신고로 끝난다.
2. **링크보다 정보가 먼저다.**
   - 외부 글은 그 자리에서 완결되는 정보로 쓰고, "전체 일정은 여기 모아 둠" 링크는 1개만 단다.
   - 같은 곳에는 하루 1회까지만 올린다.
3. **카톡방의 약점을 노린다.**
   - 메시지가 하루 수천 개라 정보가 묻히고, 같은 질문이 반복된다.
   - 노방장은 날짜순 정리, 검색, 남는 글로 답한다.
4. **노방장 사이트 안 글·카드·답글은 행동 유도 5개 중 1개.** "댓글 남겨 주세요", "~하는 분?"으로 끝내지 않고 사실·정리로 끝낸다. 인스타·스레드·유튜브 게시물은 행동 유도로 끝나도 된다(10/24 사용자).
5. **모든 링크에 `?from=채널`을 단다.** 예: `?from=kakao`, `?from=cafe_<이름>`, `?from=threads`, `?from=dc_<갤>`.
   - 카톡에는 미리보기가 안 뜨는 `/k/<코드>` 짧은 링크를 쓴다.
6. **검색어를 제목에 그대로 쓴다.** 예: "부모급여 신청 방법 2026", "11월 마라톤 접수 일정", "이번 주 SNKRS 발매".

## 3. 입소문 설계: STEPPS (Jonah Berger 『컨테이저스 전략적 입소문』)
| 원칙 | 노방장 공통 장치 | 방별 예 |
|---|---|---|
| Social currency (자랑거리) | 1분 테스트 결과, 순위, 황금귀 점수 | 러너 타입, 응원 팀 순위, 육아 타입 부부 공유 |
| Triggers (떠올릴 계기) | 요일·시간 고정 발행, 시즌 달력 | 월요일 발매 정리, 경기일, 밤 10시 육아 정보 |
| Emotion (감정) | 공감·위로·놀람 | 육아 하소연, 직관 후기, 첫 완주 |
| Public (보이게) | 자랑 탭, 결과 카드, 공유 이미지 | 착샷, 메달, 장비 사진 |
| Practical value (실용) | 행사·할인·발매 한 장 정리 | 드로우 일정, 쿠폰, 접수 마감, 지원금 |
| Stories (이야기) | "묻히는 정보를 남기려고 만들었다"는 운영자 이야기 | 방마다 한 문장 (각 파일 9번) |

## 5. 대표님만 할 수 있는 것
- **카톡 오픈채팅·맘카페·네이버 카페·디시에 글 올리기:** 홍보 AI가 문구를 준비하고, 대표님이 붙여 넣는다.
  - 오픈채팅은 방장에게 1:1로 먼저 허락을 받는다.
- **외부 커뮤니티 회원수 확인:** 이 조사 환경에서는 네이버·디시·인스타가 막혀 "미확인"이 많다.
  - 각 파일의 "직접 확인할 것"을 휴대폰으로 채운다.

## 6. 홍보 AI
예약 작업 "노방장 홍보 AI"가 매일 아침 이 문서를 읽고 아래를 한다.
1. **오늘의 방 2곳 고르기:** 우선순위 방을 먼저, 나머지는 차례로.
   - 각 파일에서 그 방 섹션의 2주 실행표 중 오늘 할 일을 찾는다.
2. **노방장 안에 쌓을 글 1~2개 올리기:** 검색어 제목의 정보 글로, 운영 닉네임으로 올린다.
   - 사실만 쓰고 출처 링크를 단다. 행동 유도는 5개 중 1개.
3. **대표님이 붙여 넣을 외부용 문구 1~2개 준비:** 대화창에 코드블록으로 준다.
   - 채널, 규칙 메모, `?from=` 링크, 운영자 신분 문장을 함께 준다.
4. **어제 숫자 보기:** /admin, /admin/business에서 유입, 재방문, 방별 채팅 글 수를 본다.
   - 잘 된 채널·문구는 이 문서 아래 "배운 것"에 한 줄씩 적어 다음에 반영한다.
5. SNS 예약은 기존 "SNS 방별 예약" 작업이 맡는다. 홍보 AI는 그 작업이 쓸 방별 소재 아이디어를 "배운 것"에 남긴다.
