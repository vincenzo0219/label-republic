# 노방장 SNS 플레이북 (릴스·쇼츠·스레드)

작성 2026-11-11. 목표: 게시물 1개당 조회 1만.
매일 분량(운영자 규칙): 인스타 릴스 2 + 유튜브 쇼츠 2(같은 영상) + 스레드 3.
지금 위치(최근 7일): 쇼츠 최고 1,053(반응속도 결투), 애니 초성 528/395 · 릴스 최고 100~190, 11/9~11/10 릴스 0회 · 스레드 정보글 47~58, 최고 284(웹소설 글자 수) · "어제 정답" 글과 릴스 재게시 1~5.
결론: 잘 된 것(반응속도 대결, 실제 숫자 정보)은 늘리고, 1~5회짜리 형식은 오늘부로 끊는다.

> 이 문서의 모든 전술은 7장 "하지 말 것"보다 아래에 있다. 충돌하면 7장이 이긴다.

## 1. 핵심 원칙 10개

1. **첫 화면이 곧 훅이다.** 첫 프레임만 보고도(소리 없이) 무슨 영상인지, 왜 봐야 하는지 알게 한다. (Jenny Hoyos)
2. **약속을 먼저 말하고, 약속을 지키고, 바로 끝낸다.** 보상을 앞에 예고하고, 보여준 직후 끊는다. 끝을 1초 줄여 시청 유지율이 오른 사례가 있다. (Jenny Hoyos)
3. **패키징이 안 되면 아이디어가 아니다.** 제목·첫 프레임 한 줄로 클릭 이유를 못 만들면 그 영상은 찍지 않는다. (Paddy Galloway)
4. **아웃라이어만 본다.** 평균 영상은 무시하고, 평균보다 크게 튄 영상 1개를 찾아 같은 형식으로 반복하고 살짝 비튼다. 시청자는 "새것"보다 "좋았던 것 또 보기"를 더 원한다. (Paddy Galloway)
5. **처음 1분(쇼츠는 처음 1~3초)에 가장 공을 들인다.** 첫 구간은 썸네일·제목에서 기대한 것이 진짜 나온다는 걸 증명하는 자리다. (MrBeast 제작 가이드)
6. **진행은 빠르게, 중간에 다시 붙잡는다.** 초반에 이야기를 빠르게 밀고, 지루해질 시점에 한 번 더 "와" 하는 장면(re-engagement)을 넣는다. 지표는 CTR·평균 시청 시간(AVD)·평균 시청 비율(AVP). (MrBeast 제작 가이드)
7. **제목·썸네일은 궁금증, 본편은 답.** 역할을 나누고, 본편에서 제목을 반복하지 않는다. 잘 된 영상은 구조와 소재를 벤치마킹하되 문장·썸네일·대본은 절대 베끼지 않는다. (주언규)
8. **노출은 기다리지 말고 스스로 만든다.** 올린 직후 외부(스레드, 방 안내, 지인 공유)로 첫 시청을 붙인다. 제목·자막·내용이 같은 주제를 가리켜야 알맞은 사람에게 추천된다. (유튜브 훈련소 쇼츠 "유튜브 노출도는 스스로 올리세요", 관련 일반 자료)
9. **아무도 안 봐도 계속 올린다, 단 매번 하나는 고친다.** 초반 0~수십 회는 정상이다. 끊지 말고 올리되 같은 실수를 반복하지 않는다. (애드 "아무도 내 영상을 안 볼 때, 이렇게 해보세요." 썸네일 "계속 올리세요")
10. **욕망과 두려움, 단 정직하게.** 사람은 얻는 기쁨보다 잃는 아픔에 더 크게 반응한다(손실 회피, 카너먼). 실제 마감·실제 숫자·실제 도전만 쓴다. 과하게 쓰면 신뢰를 잃는다. (국내 마케팅 카피 자료, 손실 회피 이론)

부가 근거: 인스타 릴스 추천 상위 신호는 시청 시간, 도달 대비 좋아요, 도달 대비 공유(DM 보내기)라고 모세리가 2025년 1월 밝혔다고 다수 자료가 전한다. 특히 "보내기"는 팔로워 밖 도달에 중요하다. 유튜브 쇼츠는 "조회함 vs 넘김" 비율과 재시청이 핵심이다.

## 2. 훅 공식

### 2-1. 훅에 쓰는 감정 6가지 (정직한 버전만)

| 감정 | 정직하게 쓰는 법 | 금지 |
|---|---|---|
| 도전·자존심 | "3초 안에 돼요?" 실제로 3초 안에 가능한 문제만 | 불가능한 걸 가능한 척 |
| 호기심 | 정답 직전에 끊고 "정답은 방에서" | 영상에 없는 걸 있는 척 |
| 손실 회피(두려움) | 실제 마감: "11/23 마감, 놓치면 내년" | 가짜 마감, 건강·안전·돈 공포 |
| 지위 | "랭킹 1위 기록 [실제 기록]" (랭킹이 실제로 있을 때만) | 지어낸 순위·통계 |
| 소속 | "K리그 팬이면", "애니 좀 본 사람" | 특정 집단 조롱 |
| 비교·대결 | "친구랑 같이 해보세요, 누가 빨라요?" | 상대 비하 |

숫자는 실제 기록·실제 데이터일 때만 쓴다. "90% 틀림" 같은 말은 실제 집계가 있을 때만.

### 2-2. 첫 0.5초 화면·문구 템플릿 15개

괄호 [ ] 안은 그날 실제 값으로 채운다. 화면 = 첫 프레임에 보이는 것, 문구 = 상단 큰 자막.

**게임 릴스·쇼츠 (1~10)**

1. 화면: 반응속도 대기 화면 클로즈업 · 문구: **"색 바뀌면 바로 탭. 몇 ms 나와요?"** (반응속도, 현재 최고 성과 형식)
2. 화면: 두 기록 나란히 · 문구: **"[A] [실제 ms] vs [B] [실제 ms], 누가 이김?"** (대결)
3. 화면: 책 첫 문장 한 줄 크게 · 문구: **"이 첫 문장, 무슨 책인지 3초 안에?"** (도전)
4. 화면: 초성 한 칸 클로즈업 · 문구: **"이 초성 보고 바로 떠오르면 애니 좀 본 사람"** (소속·자존심)
5. 화면: 60초 타이머 시작 순간 · 문구: **"60초에 몇 개? 제 기록은 [실제 개수]개"** (보상 먼저 말하기)
6. 화면: 구단 엠블럼 없이 구단명·구장명 카드 · 문구: **"K리그 팬이면 이 짝 실수 없이 가능?"** (소속)
7. 화면: 내가 틀리는 장면(실제 녹화) · 문구: **"저는 여기서 틀렸습니다. 님은?"** (공감·도전)
8. 화면: 정답 공개 직전 정지 · 문구: **"정답 나오기 직전에 멈춥니다. 맞혀보세요"** (호기심, 정답은 방에서)
9. 화면: 친구 둘이 하는 장면 또는 2인 기록 · 문구: **"친구한테 보내서 누가 빠른지 재보세요"** (공유 신호 겨냥)
10. 화면: 그날 문제 화면 · 문구: **"오늘 문제는 [실제 교체 시각]에 바뀜"** (실제 교체 시각을 확인한 날만, 손실 회피)

**스레드 (11~15)**

11. **"[실제 날짜] [행사/마감] 마감. 놓치면 [실제 다음 기회]"** (손실 회피, 실제 일정만)
12. **"[주제] [단위], 실제로는 [출처 있는 숫자]"** 예: 웹소설 글자 수형 (현재 최고 성과 형식)
13. **"첫 문장만 보고 맞힐 수 있는 책, 하나만 대 보세요"** (한 줄 질문, 댓글 유도)
14. **"[취미] 하는 사람만 아는 것 하나"** (소속, 내용은 사실만)
15. **"이거 모르고 [취미] 시작하면 [구체적이고 사소한 손해: 시간·재료 낭비]"** (모르면 손해, 건강·안전·돈 공포 금지)

## 3. 릴스·쇼츠 구조

| 구간 | 할 일 |
|---|---|
| 0~1초 | 첫 프레임 = 문제 화면 + 큰 자막 1줄(12자 안팎). 로고·인사·로딩 화면 금지. 이미 게임이 진행 중인 장면에서 시작 |
| 1~6초 | 보상 예고("마지막에 [기록/정답 직전]") 후 바로 진행. 화면이 2초 이상 멈추면 자르기 |
| 중간 | 한 번 "와" 장면: 아슬아슬한 정답, 기록 갱신, 마지막 1초 성공 (MrBeast re-engagement의 쇼츠판) |
| 끝 2초 | 약속을 지킨 직후 끊기. 정답 직전 정지 + "정답은 방에서" 또는 첫 프레임과 이어지는 장면으로 끝내 자연 루프 |
| 길이 | 기본 15~30초. 반응속도는 10~15초. 30초 넘기려면 중간 "와" 장면이 있어야 함 |
| 자막 | 소리 없이도 이해되게. 화면 위·아래 버튼 영역 피해서 가운데 위쪽. 한 화면 한 줄 |
| 소리 | 탭·정답·타이머 효과음 살리기. 내레이션은 짧게. 저작권 불명 음원 금지(플랫폼 제공 음원만) |
| 편집 | 실제 화면 녹화 그대로(조작 금지). 대기·로딩 구간만 자르기. 앱 워터마크 없는 원본으로 내보내기 |

릴스 0회 대응(11/9~11/10): 인스타 "계정 상태"에서 추천 가능 여부 먼저 확인 → 문제 표시가 있으면 그 화면에서 검토 요청 → 다른 앱 워터마크·재게시 영상·제한된 해시태그 쓰지 않기 → 한 시간 만에 0은 지연일 수 있으니 하루 뒤 다시 확인.

## 4. 패키징

### 유튜브 쇼츠 제목 (40자 안쪽, 질문 또는 대결)
- "[게임] [도전 조건] 가능? | 노방장"  예: "애니 초성 60초, 몇 개까지 가능? | 노방장"
- "[A] vs [B] 반응속도, 누가 이김?"
- "책 첫 문장만 보고 제목 맞히기 #[번호]"  (시리즈 번호로 반복 시청 유도)
- 제목·자막·설명이 같은 주제 단어를 써야 함(책/애니/K리그/반응속도).

### 첫 프레임 (썸네일 겸용)
- 문제 화면 + 큰 글자 1줄 + 숫자 1개(타이머, ms, 남은 개수).
- 글자는 휴대폰 화면 1/3 이내, 대비 강하게, 한 번 보고 이해(글랜스 테스트).
- 매번 같은 위치·같은 색으로 시리즈처럼 보이게.

### 캡션 첫 줄 (인스타·유튜브 설명)
- 1줄: 훅 질문 반복 아님, 행동 지시. "기록 댓글로 남겨 주세요" / "친구한테 보내서 대결"
- 2줄: 방 링크. "👉 nobangjang.com/games/[게임]"
- 3줄: 해시태그 3~5개(주제 일치하는 것만).

## 5. 스레드 3개 형식별 템플릿

**① 날짜·숫자 정보 (매일 1, 현재 최고 형식)**
```
[주제] [숫자 단위], 실제로는 [출처 있는 숫자].
[한 줄 설명: 왜 그런지 사실만]
[출처: 기관/공식 페이지 이름]
[방 이름]에서 더 얘기해요 👉 nobangjang.com/[방 경로]
```
날짜형: `[실제 날짜] [일정] 마감. 놓치면 [실제 다음 기회]. 👉 [방 링크]`

**② 한 줄 훅 질문 (매일 1)**
```
[취미] 하는 분, [고르기 쉬운 질문] 하나만 대 보세요.
👉 [방 링크]
```
조건: 답이 한 단어로 나오는 질문. 정답 있는 퀴즈면 그날 정답은 쓰지 않는다.

**③ 밝은 이미지 카드 또는 팁 (매일 1)**
```
[이미지: 밝은 배경, 큰 글자 1줄]
[팁 1줄, 사실만]
[팁이 쓸모 있는 상황 1줄]
👉 [방 링크]
```
술 관련은 스레드에서만, 첫 줄에 "만 19세 이상".

**끊을 형식(1~5회):** "어제 퀴즈 정답" 글, 릴스 그대로 재게시. 대신 ①번 숫자형 비중을 늘린다.

## 6. 매일 개선 루프

### 지표 (게시 24시간 뒤 기록)
| 플랫폼 | 볼 것 |
|---|---|
| 유튜브 쇼츠 | 조회수, "조회함 vs 넘김" 비율(첫 1~3초 통과율), 평균 시청 시간, 평균 시청 비율(100% 넘으면 루프 성공) |
| 인스타 릴스 | 조회수, 3초 이상 시청/건너뛰기 비율(제공 시), 평균 시청 시간, 보내기(공유)·저장 수 |
| 스레드 | 조회수, 답글 수, 재게시 수 |

### A/B 규칙
1. 하루에 **한 가지만** 바꾼다: 훅 문구 / 첫 프레임 / 길이 / 끝 처리 / 게시 시간 중 하나.
2. 하루 쇼츠 2개 = 같은 게임, 바꾼 요소 하나만 다르게(A/B).
3. 같은 변경을 3일 반복해서 평균으로 판단. 하루 결과로 결론 내지 않는다.
4. 첫 1~3초 통과율이 낮으면 → 훅·첫 프레임 고치기. 통과율은 괜찮은데 평균 시청이 낮으면 → 중간 자르기·길이 줄이기. 끝까지 보는데 공유가 없으면 → 대결·"친구한테 보내기" 장치 넣기.

### 아웃라이어 분석 (매주 일요일)
1. 플랫폼별 최근 14개 게시물 조회수 중앙값을 낸다.
2. 중앙값 3배 넘는 게시물 = 아웃라이어. 훅·게임·길이·시간을 적는다.
3. 다음 주 분량의 절반 이상을 그 형식의 변형으로 채운다(같은 틀, 다른 문제).
4. 남의 채널 아웃라이어도 본다(퀴즈·반응속도 쇼츠): 구조만 참고, 문장·화면은 새로 만든다.

### 버리기 규칙
- 같은 형식이 7개 연속 중앙값 절반 미만이면 중단.
- 현재 기준: 반응속도 대결 = 늘림, 애니 초성 = 유지·훅 실험, 스레드 숫자 정보 = 늘림, 어제 정답·재게시 = 중단.

### 꾸준함
- 분량(릴스 2·쇼츠 2·스레드 3)은 성적과 상관없이 지킨다. 대신 매일 하나씩 고친다. (애드, 유튜브 훈련소)
- 올린 직후 30분 안에 스레드 ①·② 중 하나로 그 게임 방을 안내해 첫 시청을 만든다.

## 7. 하지 말 것 (모든 전술보다 우선)

- 지어낸 숫자·통계·후기·경험 금지. "90% 틀림"은 실제 집계가 있을 때만.
- 오해를 부르는 낚시 금지: 영상에 없는 장면을 첫 화면·제목에 쓰지 않는다.
- 건강·안전·돈에 대한 공포 조장 금지. 주식 종목·투자 조언 금지.
- 술은 스레드에서만, "만 19세 이상" 표기.
- 정치 금지, 특정 집단·사람 조롱 금지.
- 엠대시 기호 금지(쉼표·마침표·콜론으로).
- 일본 국기 이모지 금지.
- 모든 게시물에 해당 방 링크.
- 그날 퀴즈 정답 공개 금지(영상은 정답 직전에 끊고, 글에도 쓰지 않는다).
- 남의 썸네일·제목·대본 베끼기 금지(구조만 참고).
- 다른 앱 워터마크 붙은 영상, 같은 영상 재게시로 숫자 채우기 금지.
