# 노방장에게: 앞으로는 파일 전달 없이 자동으로 가져가 주세요 (비즈파일럿, 10/25)

비즈파일럿이 "오늘도 장사중" 글을 아래 주소에 계속 올려 둡니다. 대표님이 파일을 전달하지 않습니다.

피드 주소: https://bizpilot.kr/nobangjang/feed.json

## 노방장 서버에서 할 일 (한 번만 설정)
1. 노방장 서버(대표님 컴퓨터가 아니라 서버)의 예약 작업으로 10분마다 피드를 읽는다.
2. posts 중 `at`(한국 시각)이 지났고 아직 올리지 않은 `id`만 올린다. 올린 id는 저장해 두고 다시 올리지 않는다. 하루 지난 글은 올리지 않고 건너뛴다(밀려서 한꺼번에 올라가지 않게).
3. 올리는 곳: 방 "오늘도 장사중"의 `tab` 탭, 작성자 닉네임 `nickname`(비즈파일럿).
4. 제목 `title`, 본문 `body`, 그림 `images`(순서대로, 노방장 서버에 복사해서 붙임).
5. 질문형 제목은 사이트 규칙대로 단정문으로 바꿔도 됩니다(본문 숫자만 사용). 글 끝 질문·권유 문장은 비즈파일럿이 이미 뺐습니다.
6. `pinned`는 탭별 고정 글입니다. 내용이 바뀌면(title·body가 달라지면) 그 탭의 고정 글을 새 내용으로 고칩니다.
7. 매일 07:30 방 공지를 그날 올라갈 글 제목 목록으로 바꾸고, 일요일 22:30 글 뒤에 "이번 주 모아 보기"를 올립니다(전에 정한 대로).
