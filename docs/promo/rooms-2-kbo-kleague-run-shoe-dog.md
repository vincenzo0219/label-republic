# 노방장 방별 홍보 전략 B (KBO · K리그 · 러닝 · 신발 · 반려견)

작성 기준일: 2026-10-24. 카톡 내보내기 파일이 없는 방이라 5번 섹션은 웹 공개 자료와 일반적 관찰로 쓰고, 확인 못 한 수치는 "미확인"으로 적었다.

## 공통 메모 (5개 방 모두 해당)

- 조사 한계: 이번 조사 환경에서는 네이버 카페, 디시인사이드, 인스타그램 페이지에 직접 접속하지 못했다(프록시 차단). 그래서 **카페 회원수, 갤러리 개설일, 인스타 해시태그 게시물 수는 기사나 위키로 확인한 것만 수치로 적고 나머지는 "미확인"으로 둔다.** 대표님이 휴대폰으로 1회 확인해 표를 채우면 된다(각 방 2번 섹션 "직접 확인할 것" 칸).
- 유입 측정: 모든 외부 링크에 `?from=채널명_방슬러그` 형식을 붙인다. 예: `nobangjang.com/kbo-test?from=threads_kbo`, `?from=dc_kbo`, `?from=cafe_dog`.
- 운영자 공개 문구(외부 커뮤니티 공통): "노방장 만든 사람입니다. 홍보 금지 게시판이면 지워 주세요." 를 외부 글 첫 줄 또는 끝 줄에 넣는다. 닉네임도 "노방장_운영자" 처럼 신분이 보이게 쓴다.
- 금지: 가짜 계정, 지인 동원 추천·댓글, 같은 글 여러 게시판 복붙, 홍보 금지 게시판 우회(이미지 속 링크, 단축 URL 숨기기 등), 추천인 링크.
- 링크 규칙: 외부 커뮤니티 질문에 링크로 답하는 것은 하루 1회까지. 나머지 답은 링크 없이 내용으로만 한다.
- 행동 유도 문장 비율: 노방장 운영 글 5개 중 1개 이하만 "댓글 남겨 주세요/테스트 해 보세요"로 끝낸다. 나머지는 정보로 끝낸다.
- AI 자동 vs 대표님 직접: Metricool 예약(인스타 12, 스레드 17, 유튜브 8/일)은 AI가 만든다. 외부 커뮤니티 글·댓글, 오픈채팅 참여, 운영자 신분 공개가 필요한 활동은 대표님이 직접 한다.

### 8. 입소문 설계 (STEPPS)

- **Social currency**: `/kbo-test` 결과 카드에 "○○ 팬 상위 몇 %" 같은 표시(실제 집계 기반만). 팀 팬 순위에서 "우리 팀 팬이 제일 많이 참여" 를 자랑거리로.
- **Triggers**: 경기 시작 18:30, 선발 예고, 우천 순연, 골든글러브 발표 같은 반복 신호마다 같은 형식 글을 올려 "선발 나오면 노방장" 습관을 만든다.
- **Emotion**: 가을야구 긴장감과 아쉬움. "올해 우리 팀에게 한마디" 글(감정 높은 각성 감정: 흥분·분노·감동)을 시즌 종료 직후 올린다.
- **Public**: 팀 팬 순위 그래픽을 인스타 스토리용 9:16으로 만들어 팬이 공유하기 쉽게. 결과 카드에 nobangjang.com 워터마크.
- **Practical value**: 예매 시간, 우천 규정, 경기장 주차·셔틀, FA 규정 정리. 단톡방에서 매번 다시 묻는 것을 한 글에 고정.
